# DrakesCraft Labs Maven Repo

Repositorio Maven publico para artefactos internos del stack Drake/Slimefun.

URL de consumo:

```xml
<repository>
  <id>drakescraft-labs-maven</id>
  <url>https://drakescraft-labs.github.io/maven-repo/</url>
</repository>
```

Artefactos publicados inicialmente:

- `com.github.drakescraft_labs:slimefun-core:11.0-Drake-1.21.1-SNAPSHOT`
- `com.github.drakescraft_labs:dough-core:1.3.1-DRAKE-v11-SNAPSHOT`
- `com.github.drakescraft_labs:sefilib-drake:0.3.1-DRAKE-SNAPSHOT`
- `com.github.drakescraft_labs:InfinityExpansion-drake:1.20.6-Drake-SNAPSHOT`

Este repositorio esta pensado para compilar plugins separados de DrakesCraft sin depender de un reactor local ni de la cache Maven de una maquina especifica.
